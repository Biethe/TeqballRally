# Character animation metadata
#
# Frames are Blender frame numbers. `contactFrame` is the ball-contact frame;
# `ballLeaveHand` is used for serves. The runtime copy lives in src/config.ts.
#
# "InPlace" clips keep the feet under the rig instead of travelling. Movement
# here is kinematic — the character's position is integrated from its velocity
# — so a clip that also translates the root would move it twice and drift it
# away from where the game thinks it is. Locomotion therefore uses the InPlace
# strafes; the travelling JogStrafeLeft/Right are kept for reference.
